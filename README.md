# AI Chatbot with NLP

## Project Overview
The AI Chatbot with NLP project uses Natural Language Processing to improve human–computer interaction. It understands user input and generates relevant and intelligent responses. This chatbot is useful for academic projects, internships, and customer support applications.

## Objectives
- Understand human language
- Develop an automated conversation system
- Create a user-friendly chatbot
- Reduce manual interaction

## Technologies Used
- Python
- Natural Language Processing (NLP)
- NLTK / SpaCy
- Scikit-learn
- Flask (optional – for web app)

## Features
- Text-based user interaction
- NLP-based input processing
- Intent recognition
- Predefined and dynamic responses
- Easy training with new data
- Scalable chatbot design

## How to Run the Project

1. Clone the repository
git clone https://github.com/Supriya-03092005/AI-CHATBOT-WITH-NLP

2. Install required libraries
pip install -r requirements.txt

3. Train the chatbot model
python train.py

4. Run the chatbot
python chatbot.py
